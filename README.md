# 📰 Fake News Detection using Machine Learning

This project is a Machine Learning based Fake News Detection system that predicts whether a given news article is **Fake or Real**.

The project uses Natural Language Processing (NLP) techniques to process news text and a Machine Learning model to classify the news.

---

## 📌 Project Overview

Fake news is misleading or false information presented as real news.  
This project aims to automatically detect fake news using Machine Learning and Natural Language Processing.

The system takes the **news title/text as input** and predicts whether it is:

- ✅ Real News
- ❌ Fake News

---

- Fake news classification using Machine Learning
- Text preprocessing using NLP

## 🤖 Machine Learning

The project uses **TF-IDF (Term Frequency-Inverse Document Frequency)** to convert news text into numerical features.

The trained Machine Learning model then uses these features to classify the news as Fake or Real.

### Workflow

News Text  
↓  
Text Preprocessing  
↓  
TF-IDF Vectorization  
↓  
Machine Learning Model  
↓  
Fake / Real Prediction

---

## 📊 Model Performance

**Accuracy: 99.48%**

The model was evaluated on the available dataset and achieved approximately **99.48% accuracy**.

> Note: Accuracy depends on the dataset, preprocessing, train-test split, and evaluation method.
